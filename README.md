# RoTab documentation

RoTab is a Chromium new-tab extension for protein visualization and browser-based Rosetta computation. Its standalone WebAssembly library exposes selected Rosetta methods to other browser applications.

[Documentation website](https://salireza111.github.io/RoTab_Doc/)

This repository contains the user guides, illustrated Help, architecture reference, standalone API documentation, and validation summaries. It covers molecular visualization, local calculations, volunteer connections, job assignment, data handling, and the scientific scope of the port.

The documentation is separate from the extension and scientific runtime. Rosetta executables, database assets, participant records, and authentication material are not distributed here.
